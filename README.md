### 🚀 Highlighted Project

#### 🤖 [JAVI — Autonomous Offline Voice & Desktop Agent](https://github.com/jeevannag07-jpg/javi)
*An intelligent, zero-latency desktop co-pilot running locally on Windows.*
- **Core Stack:** Python, Ollama (`qwen2.5:3b`, `llava:7b`), OpenWakeWord (ONNX), SQLite, Win32/pycaw.
- **Key Features:** Streaming sentence-by-sentence TTS (<300 ms response latency), persistent SQLite conversation memory, native Windows volume/media telemetry, screen analysis, and background system tray persistence.
